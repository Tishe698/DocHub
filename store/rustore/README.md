# Публикация MedRush в RuStore

Всё для загрузки в [консоль RuStore](https://console.rustore.ru): тексты карточки, настройки,
скриншоты, иконка и порядок действий. Требования RuStore — по
[справке для разработчиков](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/requirement-apps)
на 24 октября 2026 г.; перед загрузкой сверьте их в консоли.

## Сначала — прошлая блокировка

Прежняя версия приложения в RuStore была заблокирована. Новое имя пакета
(`com.pulsetech7812.medrush`), новое название и новый ключ причину блокировки не снимают: если повторить то же
нарушение, RuStore может ограничить весь аккаунт разработчика.

1. Откройте уведомление о блокировке в консоли RuStore и найдите причину.
2. Если причина неясна — напишите на support@rustore.ru. Решение модерации можно обжаловать
   письмом туда же (одна апелляция на решение, рассмотрение до 30 дней).
3. Убедитесь, что причина устранена в этой версии. Уже сделано:
   - убрано видео с водяным знаком стороннего автора (`fb.com/ScienceNaturePage`) — без прав
     на него это нарушение соглашения разработчика (п. 7.4, 9.2, 9.3);
   - добавлены экран «Перед началом работы» и политика конфиденциальности;
   - назначение везде описано одинаково: справочно-информационное приложение, решение принимает
     медицинский работник.

Статус приложения как медицинского изделия однозначно не определён: расчёты по формулам
медизделием не считаются, а шкалы оценки риска — серая зона (письмо Росздравнадзора
от 13.02.2020 № 02И-297/20). Для уверенности нужно заключение юриста по медицинскому праву или
консультация ВНИИИМТ.

### Полное описание (до 4000)

```
MedRush — справочно-информационное приложение для бригад скорой медицинской помощи, педиатров и студентов медицинских вузов. Оно показывает расчёты по формулам и таблицам из клинических рекомендаций Минздрава России, инструкций к препаратам и международных руководств (ERC, AHA/PALS). У каждого результата видны введённые данные и источник. Приложение не ставит диагноз и не назначает лечение: решение принимает медицинский работник.

Работает без интернета. Данные пациента вводятся один раз — масса, возраст, пол, рост или зона ленты Broselow — и подставляются во все расчёты.

Что есть в приложении:
• Расчёт препаратов — 128 препаратов, у 122 есть расчёт дозы и объёма по массе и возрасту. Путь введения и показание выбираются кнопками, доза не превышает максимум из инструкции, результат можно скопировать.
• Норадреналин — скорость шприцевого насоса и капельницы.
• Дефибриллятор — энергия разряда для взрослого и ребёнка на ступенях конкретного аппарата (LIFEPAK 15, ZOLL, Аксион, Philips, Mindray и др.), кардиоверсия, кардиостимуляция, порядок действий.
• Интубация — размер и глубина эндотрахеальной трубки по росту, ленте Broselow, возрасту или массе; ларингеальная трубка.
• Кислород и ИВЛ — время работы баллона, минутный объём дыхания, стартовые параметры аппаратов ИВЛ.
• Шкалы — NEWS2, шкала комы Глазго, шоковый индекс Альговера, пересмотренная Женевская шкала, ШОКС.
• Педиатрия — нормы по возрасту, шкала Апгар с секундомером.
• Справочники — МКБ-10 (поиск по коду и названию), группа крови по таблице цоликлонов, срок беременности и дата родов.

Светлая и тёмная тема, крупный шрифт, работа с TalkBack.

Конфиденциальность: приложение не собирает и не передаёт данные, не показывает рекламу. Данные пациента хранятся только в памяти телефона до закрытия приложения.

Расчёты справочные. Перед применением сверяйте дозу, концентрацию и путь введения с инструкцией к препарату и клиническими рекомендациями, а размер трубки — с маркировкой производителя.
```

## Ключ подписи

Ключ создаёте вы сами — пароль знаете только вы. Храните файл ключа и пароль в надёжном месте:
без них нельзя выпустить обновление (смена ключа — только через поддержку RuStore).

```bash
/opt/homebrew/opt/openjdk@17/bin/keytool -genkeypair -v -keystore ~/keystores/dochub/medrush-rustore.keystore -alias medrush -keyalg RSA -keysize 4096 -validity 10000
```

`keytool` спросит пароль и данные владельца (имя, город, страна — можно латиницей).

## Сборка и подпись APK

RuStore принимает APK и AAB. С APK проще: ключ отдельно загружать не нужно.

1. Сборка под телефоны ARM (около 45 МБ):

   ```bash
   npx expo prebuild --platform android --clean --no-install
   ```

   ```bash
   cd android && ANDROID_HOME=$HOME/Library/Android/sdk JAVA_HOME=/opt/homebrew/opt/openjdk@17 NODE_ENV=production ./gradlew assembleRelease -PreactNativeArchitectures=armeabi-v7a,arm64-v8a
   ```

2. Подпись своим ключом (`apksigner` спросит пароль и заменит отладочную подпись):

   ```bash
   $HOME/Library/Android/sdk/build-tools/36.1.0/apksigner sign --ks ~/keystores/dochub/medrush-rustore.keystore --ks-key-alias medrush --out ~/Desktop/MedRush-1.0.0-rustore.apk android/app/build/outputs/apk/release/app-release.apk
   ```

3. Проверка подписи:

   ```bash
   $HOME/Library/Android/sdk/build-tools/36.1.0/apksigner verify --print-certs ~/Desktop/MedRush-1.0.0-rustore.apk
   ```

Для RuStore собирайте только так, локально: `versionCode` берётся из `app.json`
(`android.versionCode`). Профиль `production` в `eas.json` ведёт свой счётчик версий на серверах
Expo (для Google Play), поэтому сборки для RuStore через EAS не делайте — иначе номер может
оказаться не больше прежнего, и RuStore отклонит обновление.

Каждое следующее обновление: тот же ключ, тот же пакет и `versionCode` больше прежнего.

## Порядок загрузки

0. Слейте ветку с этими изменениями в `main` и откройте ссылку на политику
   (https://github.com/Tishe698/DocHub/blob/main/PRIVACY.md) в браузере без входа в GitHub:
   до слияния её там нет, а модерация проверяет, что политика открывается.
1. Войдите в консоль RuStore через VK ID и зарегистрируйте аккаунт разработчика (физлицо, ИП или
   юрлицо; для бесплатного приложения подходит любой).
2. «Приложения» → «Создать приложение» → тип «Бесплатное».
3. Загрузите `MedRush-1.0.0-rustore.apk`.
4. Заполните карточку по таблице выше, загрузите иконку и скриншоты.
5. Заполните анкету «Безопасность данных».
6. Выберите ручную публикацию и отправьте на модерацию. Срок — до нескольких дней; если
   модератор запросит документы, срок начнётся заново.
7. После одобрения нажмите «Опубликовать».
