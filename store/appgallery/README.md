# Публикация MedRush в Huawei AppGallery

Карточка повторяет RuStore: те же тексты, превью, категория и рейтинг. Сборка тоже та же —
APK `MedRush-1.0.0-rustore.apk` с тем же ключом. Тексты и порядок сборки описаны в
[README для RuStore](../rustore/README.md). Здесь — только то, чем AppGallery отличается.

Требования — по [справке AppGallery Connect](https://developer.huawei.com/consumer/en/doc/app/agc-help-releaseapkrpk-0000001106463276)
(обновлена 01.06.2026); перед загрузкой сверьте их в консоли.

## Аккаунт разработчика (делает владелец)

1. Войдите в [AppGallery Connect](https://developer.huawei.com/consumer/ru/service/josp/agc/index.html)
   через Huawei ID (если его нет — создайте).
2. Зарегистрируйтесь как разработчик: тип **физическое лицо**, подтверждение личности по паспорту.
   Регистрация бесплатная; проверка документов занимает несколько рабочих дней.
3. После подтверждения: «Мои приложения» → «Новое приложение», пакет `com.pulsetech7812.medrush`,
   язык по умолчанию — русский.

## Анкета о данных и разрешениях

- Приложение собирает данные пользователей: **нет**.
- Опасные разрешения: **нет**. В сборке только `INTERNET` (служебное разрешение React Native;
  приложение в сеть не ходит).
