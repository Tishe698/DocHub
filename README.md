# DocHub — справочник и калькуляторы для СМП и педиатрии

[![Expo](https://img.shields.io/badge/Expo%20SDK-54-black.svg)](https://expo.dev/)
[![React Native](https://img.shields.io/badge/React%20Native-0.81.5-blue.svg)](https://reactnative.dev/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

**DocHub** — офлайн-приложение для Android и iOS. В нём расчёт доз препаратов, подбор
эндотрахеальной и ларингеальной трубок, кислородные расчёты, параметры ИВЛ и клинические шкалы
для бригад скорой медицинской помощи и педиатров. Интернет для работы не нужен: препараты, нормы
и МКБ-10 хранятся внутри приложения.

> **Расчёты справочные и требуют клинической проверки перед применением.** Приложение не заменяет
> клинические рекомендации, инструкцию к препарату и решение врача. Клинические значения этой
> версии ещё должен подтвердить врач — см. раздел [«Клинические источники»](#клинические-источники).

## Возможности

### Общее для всех экранов

- **Общий пациент.** Полоса пациента (масса, возраст в годах и месяцах, пол, рост, зона ленты
  Broselow) есть на главном экране и на экранах расчётов. Данные, введённые один раз, подставляются
  во все калькуляторы. Массу можно оценить по возрасту (APLS) или по зоне ленты Broselow, такая
  масса помечается как оценка. Кнопка «Новый пациент» очищает данные во всех экранах. Данные
  пациента хранятся только в памяти и пропадают при закрытии приложения.
- **Тема оформления:** «Авто» (как в настройках телефона), «Светлая», «Тёмная». Переключатель
  находится внизу главного экрана, выбор сохраняется.
- **Доступность:** подписи для TalkBack и VoiceOver на русском языке, результат озвучивается,
  размер зоны касания не меньше 48 точек, вёрстка рассчитана на системный шрифт до 150 %.
  Смысл результата передаётся словами, а не только цветом.

### Препараты

- **Расчёт препаратов** — 128 записей, у 122 есть расчёт дозы и объёма, 6 справочных (без расчёта).
  Числа приведены на момент обновления документации, актуальные показаны на экране. Поиск по МНН,
  торговым и привычным названиям («анальгин», «адреналин», «реланиум», «аспирин», «лазикс»).
  Для многих препаратов можно выбрать **путь введения** (в/в, в/к, в/м, п/к, внутрь, ректально,
  защёчно, интраназально, под язык) и **показание**. Доза ограничивается максимумом, достижение
  предела отмечено. Результат копируется в буфер обмена текстом без эмодзи, его можно вставить
  в карту вызова. Список препаратов по группам — в [USER_GUIDE.md](USER_GUIDE.md#список-препаратов).
- **Норадреналин** — доза по основанию, скорость шприцевого насоса (мл/ч) и капельницы (кап/мин).

### Дыхательные пути и кислород

- **Эндотрахеальная трубка** — размер и глубина через рот и через нос. Порядок выбора: рост →
  зона ленты Broselow → возраст, масса и пол. Новорождённые — по массе.
- **Ларингеальная трубка VBM LT / LTS-D** — дети по массе, при массе больше 25 кг и у взрослых
  по росту.
- **Время работы баллона**, **минутный объём дыхания по Дарбиняну** (по фактической или должной
  массе), **стартовые параметры аппаратной ИВЛ** (MEDUMAT Standard / Standard², А-ИВЛ/ВВЛ/ВЧп-4/40).

### Реанимация

- **Дефибриллятор** — нужен ли разряд и какой (дефибрилляция или синхронизированная
  кардиоверсия), энергия для взрослого и ребёнка на ступени выбранного аппарата (LIFEPAK 15,
  ZOLL, Аксион, Philips, Mindray и др.), кардиостимуляция при брадикардии, электроды, действия
  по шагам и безопасность. По КР РФ 2025 и ERC 2025.

### Шкалы и индексы

- **NEWS2** — ранняя оценка тяжести у взрослых (с 16 лет): 7 параметров, шкалы SpO₂ 1 и 2,
  уровень риска, частота наблюдения и реакция.
- **Шкала комы Глазго** — взрослая и педиатрическая (до 4 лет, выбирается по возрасту пациента),
  тяжесть ЧМТ, ШКГ-З.
- **Шоковый индекс Альговера** — взрослые, дети 1–16 лет (SIPA), беременные и родильницы.
- **Шкала ТЭЛА** — пересмотренная Женевская шкала, трёх- и двухуровневая оценка.
- **ШОКС** — шкала оценки клинического состояния при ХСН (Мареев В.Ю.), ФК I–IV.

### Педиатрия и неонатология

- **Нормы в педиатрии** — масса, рост, ЧДД, ЧСС, АД и порог гипотензии; строка выбирается
  по возрасту пациента.
- **Шкала Апгар** — секундомер от рождения, оценки на 1-й и 5-й минуте и повторные оценки
  на 10-й, 15-й и 20-й минуте, интерпретация по МКБ-10 P21, копирование итога.

### Справочники

- **МКБ-10** — офлайн-поиск по коду и названию, 11 841 запись.
- **Группа крови** — выбор строки в таблице цоликлонов по рисункам капель: группа AB0 и резус
  при первичном определении.
- **Срок беременности** — срок и предполагаемая дата родов по ДПМ, информационное видео.

### Чего в приложении нет

- Сохранения результатов и истории расчётов. Сохраняется только выбранная тема.
- Учётных записей, синхронизации и передачи данных пациентов.

## Клинические источники

Приоритет источников:

1. Действующие клинические рекомендации МЗ РФ (cr.minzdrav.gov.ru), приказы и методические
   письма МЗ РФ.
2. Инструкции к препаратам, зарегистрированным в РФ (ГРЛС, grls.rosminzdrav.ru).
3. Стандарты и алгоритмы СМП РФ.
4. Если российского источника нет — ERC 2021, AHA/PALS 2020, BNF for Children, ESC, оригинальные
   публикации шкал, документация производителей трубок и аппаратов ИВЛ.

Если источники расходятся, используется российский вариант, а без него — самый консервативный.
Такие места поясняются на экране: например, доза вне инструкции РФ или путь введения, которого
нет в КР и инструкции. Путь введения, для которого у препарата нет утверждённой дозы,
не предлагается.

**Клиническая проверка.** Расчёты не прошли клиническую валидацию. Клинические значения этой
версии, включая новые препараты, пути введения и показания, должен подтвердить врач до
выпуска релиза. Перед применением проверяйте дозу, концентрацию, путь введения
и противопоказания по инструкции к препарату и действующим клиническим рекомендациям, а размеры
трубок — по маркировке и инструкции производителя.

## Быстрый старт

### Требования

- **Node.js 22** (версия задана в `.nvmrc`; минимум по `package.json` — 20.19.4, это требование
  Expo SDK 54);
- **npm**;
- **Android Studio** для сборки под Android, **Xcode** для iOS (только macOS).

### Установка и запуск

```bash
git clone <адрес репозитория>
cd DocHub
nvm use              # Node из .nvmrc
npm ci               # зависимости строго по package-lock.json

npm start            # Metro и QR-код для Expo Go
npm run android      # нативная сборка и запуск на Android (expo run:android)
npm run ios          # нативная сборка и запуск на iOS (expo run:ios)
npm run web          # веб-версия
```

В Expo Go видео на экране «Срок беременности» может не воспроизводиться, в собранном приложении
оно работает.

## Разработка: тесты, линтер, форматирование, CI

| Команда | Что делает |
|---|---|
| `npm test` | Jest (пресет `jest-expo`): тесты лежат рядом с кодом в папках `__tests__/` |
| `npx jest <путь>` | тесты одного модуля, например `npx jest news` |
| `npm run lint` | ESLint 9 (flat config `eslint.config.js`: `eslint-config-expo`, правила хуков React, `eslint-config-prettier`) |
| `npm run format` | Prettier 3 переписывает файлы (`.prettierrc`: одинарные кавычки, ширина 100, `trailingComma: all`) |
| `npm run format:check` | проверка форматирования без изменений |

Prettier не трогает `*.md`, `mkb10/mkb_data.json` и `package-lock.json` (см. `.prettierignore`).

**CI** (`.github/workflows/ci.yml`) запускается при push в `main` и на каждый pull request:
Node из `.nvmrc` → `npm ci` → `npm run lint` → `npm run format:check` → `npm test -- --ci` →
пробная сборка JS-бандла `npx expo export --platform android --output-dir dist`.

Тесты покрывают чистые модули расчётов (препараты по группам, движок калькулятора, пути введения,
трубки, кислород и ИВЛ, шкалы, нормы, беременность, группа крови, МКБ-10), контраст цветов
обеих тем и рендер экранов.

### Правила для изменений

1. Ветка: `git checkout -b feature/<название>`.
2. Логика расчёта — в чистом модуле рядом с экраном (без React), тест — в `__tests__/` рядом.
3. Новый экран: папка модуля → маршрут в `ROUTES` в `App.js` → карточка в
   `main_screen/menuConfig.js` (`route`, `section` — ключ `theme.colors.section`, `icon` — имя
   Ionicons). Тест `main_screen/__tests__/menuConfig.test.js` упадёт, если у маршрута нет карточки.
4. Экран: контейнер `components/Screen`, цвета только из `useTheme().colors`, компоненты из
   `components/ui`, данные пациента — из `patient/PatientContext`. Подробности — в
   [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
5. Новый препарат: запись в нужном файле `js_button_preparation/formula_groups/`. Путь введения —
   `routeInput([...], 'iv')`, показание — `choiceInput(...)` из `js_button_preparation/routes.js`.
6. У каждого клинического значения (доза, максимум, порог, строка таблицы) — комментарий
   с источником: документ, год, раздел.
7. Перед pull request: `npm run lint`, `npm test`, `npm run format:check`; обновите эту
   документацию.

## Сборка

### EAS Build

```bash
npx eas build --platform android --profile preview      # APK для установки
npx eas build --platform android --profile production   # сейчас тоже APK (см. eas.json)
npx eas build --platform ios --profile production
```

Для публикации в Google Play нужен AAB: в профиле `production` файла `eas.json` замените
`"buildType": "apk"` на `"buildType": "app-bundle"`.

### Проверка бандла без устройства

```bash
CI=1 npx expo export --platform android --output-dir dist
```
