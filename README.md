# 🏥 DocHub — справочник и калькуляторы для СМП и педиатрии

[![React Native](https://img.shields.io/badge/React%20Native-0.81.4-blue.svg)](https://reactnative.dev/)
[![Expo](https://img.shields.io/badge/Expo%20SDK-54-black.svg)](https://expo.dev/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

**DocHub** — офлайн-приложение (Android, iOS) с расчётами доз, подбором трубок, кислородными
расчётами и клиническими шкалами для бригад скорой медицинской помощи и педиатров.
Интернет для работы не нужен: все данные (препараты, нормы, МКБ-10) лежат внутри приложения.

> ⚠️ **Расчёты справочные и требуют клинической проверки перед применением.** Приложение не
> заменяет клинические рекомендации, инструкцию к препарату и решение врача. Подробнее — в разделе
> [«Клинические источники»](#-клинические-источники).

## ✨ Возможности

На главном экране 12 карточек.

### 🧮 Расчёты
- **Расчёт лекарств** — 81 запись о препаратах: 59 с расчётом дозы и объёма, 22 справочные
  (только текст, без расчёта). Числа на момент обновления документации; актуальные показаны в шапке
  экрана. Поиск по МНН и привычным названиям («анальгин», «адреналин», «реланиум» и др.).
  Доза ограничивается установленным максимумом, достижение предела отмечается. Результат можно
  скопировать в буфер обмена.
- **Трубки** — эндотрахеальная трубка (размер, глубина через рот и назально; дети — по длине тела
  по ленте Broselow, возрасту или массе; 13–15 лет — по возрасту и росту, не больше взрослых; с 16 лет — по полу) и ларингеальная трубка VBM LT / LTS-D
  (дети — по массе, при массе > 25 кг и у взрослых — по росту).
- **Шоковый индекс Альговера** — SI = пульс / САД; отдельные пороги для взрослых, детей 1–16 лет
  (SIPA), беременных и родильниц; у детей до 1 года не интерпретируется.
- **Кислород** — время работы баллона до резерва давления, МОД по формуле Дарбиняна, стартовые
  параметры аппаратной ИВЛ (MEDUMAT Standard / Standard², А-ИВЛ/ВВЛ/ВЧп-4/40).
- **Норадреналин** — доза по основанию, скорость шприцевого насоса (мл/ч) и капельницы (кап/мин).
- **Беременность** — срок по первому дню последней менструации (ДПМ) и предполагаемая дата родов.

### 🩺 Шкалы и справочники
- **Шкала комы Глазго** — взрослая и педиатрическая (до 4 лет), тяжесть ЧМТ, ШКГ-З (GCS-Pupils).
- **Шкала ТЭЛА** — пересмотренная Женевская шкала (8 критериев), трёх- и двухуровневая оценка
  и следующий шаг обследования.
- **ШОКС** — шкала оценки клинического состояния при хронической сердечной недостаточности
  (Мареев В.Ю.): 10 пунктов, 0–20 баллов, функциональный класс ХСН I–IV.
- **Группа крови** — интерпретация реакций с цоликлонами (анти-A, анти-B, анти-AB, контроль с 0,9%
  NaCl, анти-D): группа AB0 и резус-принадлежность при первичном определении.
- **Педиатрия** — физиологические нормы по возрасту (масса, рост, ЧДД, ЧСС, АД) и порог гипотензии.
- **МКБ-10** — офлайн-поиск по коду и названию (около 11 800 записей).

### Чего в приложении нет
- Сохранения результатов и истории расчётов: результат пропадает при закрытии окна или экрана.
- Тёмной темы: интерфейс светлый.
- Учётных записей, синхронизации и передачи данных пациентов.

## 📚 Клинические источники

Источники выбраны по приоритету:

1. Действующие клинические рекомендации МЗ РФ (cr.minzdrav.gov.ru) и приказы МЗ РФ.
2. Инструкции к препаратам, зарегистрированным в РФ (ГРЛС, grls.rosminzdrav.ru).
3. Стандарты и протоколы СМП РФ.
4. Если российского источника нет — ERC 2021, AHA/PALS 2020, BNF for Children, ESC, оригинальные
   публикации шкал, документация производителей трубок и аппаратов ИВЛ. Если источники расходятся,
   взят самый консервативный (безопасный для пациента) вариант; на экране это отмечено.

| Раздел | Основные источники |
|---|---|
| Расчёт лекарств | Инструкции ГРЛС; КР МЗ РФ; ERC 2021; PALS 2020; BNF for Children |
| Эндотрахеальная трубка | PALS 2020, ERC 2021, APLS; лента Broselow; NRP (новорождённые) |
| Ларингеальная трубка | Инструкция VBM LTS-D (2017), таблица размеров. К ларингеальной маске и i-gel не относится |
| Шоковый индекс | Allgöwer (1967); SIPA — Acker 2015, Nordin 2017; КР МЗ РФ «Послеродовое кровотечение» 2021; PALS 2020 |
| Время работы баллона | ГОСТ 5583-78 (давление баллонов); резерв 14 атм — консервативная практика СМП, его можно изменить |
| Формула Дарбиняна | Дарбинян Т.М. (1976): МОД = масса / 10 + 1 л/мин; при массе < 5 кг не применяется |
| Аппаратная ИВЛ | ERC 2021, ERC-ESICM 2021, ARDSNet (2000), PEMVECC 2017, руководства производителей аппаратов |
| Норадреналин | Инструкция ГРЛС «Норэпинефрин»; PALS 2020 (дети) |
| Беременность | КР МЗ РФ «Нормальная беременность» 2023, «Преждевременные роды» 2024 |
| Шкала Глазго | КР МЗ РФ «Черепно-мозговая травма у детей» 2025; Teasdale 2014; Brennan 2018 |
| Шкала ТЭЛА | Le Gal 2006; ESC 2019 |
| ШОКС | КР МЗ РФ «Хроническая сердечная недостаточность» 2024, приложение Г1 |
| Группа крови | Приказы МЗ РФ № 1134н (2020) и № 363 (2002) |
| Педиатрические нормы | Мазурин А.В., Воронцов И.М. «Пропедевтика детских болезней»; PALS 2015/2020 |

Источник каждого значения указан комментарием в коде рядом с ним.

**Ограничения.** Расчёты не проходили клиническую валидацию.
Перед применением проверьте дозу, концентрацию, путь введения и противопоказания по инструкции
к препарату и действующим клиническим рекомендациям, а размеры трубок — по маркировке и инструкции
производителя.

## 🚀 Быстрый старт

### Требования
- **Node.js** 20 или новее (требование Expo SDK 54)
- **npm**
- **Android Studio** — для сборки под Android, **Xcode** — для iOS (только macOS)

### Установка и запуск

```bash
git clone <адрес репозитория>
cd DocHub
npm install

npm start            # Metro + QR-код для Expo Go
npm run android      # нативная сборка и запуск на Android (expo run:android)
npm run ios          # нативная сборка и запуск на iOS (expo run:ios)
npm run web          # веб-версия
```

В Expo Go видео на экране «Беременность» может не воспроизводиться — оно работает в собранном
приложении.

## 📱 Сборка

### Локальная разработка
```bash
npx expo start --clear     # запуск с очисткой кэша
```

### EAS Build
```bash
npx eas build --platform android --profile preview      # APK для установки
npx eas build --platform android --profile production   # сейчас тоже APK (см. eas.json)
npx eas build --platform ios --profile production
```

Фрагмент текущего `eas.json`:
```json
{
  "build": {
    "preview":    { "android": { "buildType": "apk" }, "ios": { "simulator": true } },
    "production": { "android": { "buildType": "apk" }, "ios": { "buildConfiguration": "Release" } }
  }
}
```

Для публикации в Google Play нужен AAB: в профиле `production` замените `"buildType": "apk"` на
`"buildType": "app-bundle"`.

## 🤝 Разработка

1. Создайте ветку: `git checkout -b feature/<название>`.
2. Новый экран: отдельная папка модуля → `Stack.Screen` в `App.js` → карточка в
   `main_screen/button_app.js` → обновление этой документации.
3. Каждое клиническое значение (доза, максимум, порог, строка таблицы) сопровождайте комментарием
   с источником: документ, год, раздел.
4. Проверяйте расчёты на типичных и граничных значениях (масса новорождённого, взрослый, пустой ввод).
