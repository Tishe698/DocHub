> [!WARNING]

> и решение врача. Перед применением сверяйте дозу, концентрацию и путь введения с инструкцией,
> а размер трубки — с маркировкой производителя.

## Что умеет

Данные пациента вводятся один раз — масса, возраст, пол, рост, зона ленты Broselow — и сами
подставляются во все калькуляторы. Массу можно оценить по возрасту или по ленте Broselow.

| Раздел | Что считает |
|---|---|
| **Расчёт препаратов** | 128 препаратов, у 122 есть расчёт дозы и объёма. Путь введения и показание выбираются кнопками, доза не превышает максимум, результат копируется для карты вызова. Поиск по МНН и привычным названиям: «анальгин», «реланиум», «лазикс». |
| **Норадреналин** | Доза по основанию, скорость шприцевого насоса (мл/ч) и капельницы (кап/мин). |
| **Дефибриллятор** | Нужен ли разряд и какой, энергия для взрослого и ребёнка на ступенях конкретного аппарата: LIFEPAK 15, ZOLL, Аксион, Philips, Mindray, Nihon Kohden, corpuls3. Кардиостимуляция при брадикардии, электроды, действия по шагам. |
| **Интубация** | Эндотрахеальная трубка: размер и глубина через рот и нос по росту, зоне Broselow, возрасту или массе. Ларингеальная трубка VBM LT / LTS-D. |
| **Кислород и ИВЛ** | Время работы баллона до резерва, минутный объём по Дарбиняну, стартовые параметры MEDUMAT Standard / Standard² и А-ИВЛ/ВВЛ/ВЧп-4/40. |
| **Шкалы** | NEWS2, шкала комы Глазго (взрослая и детская), шоковый индекс Альговера и SIPA, пересмотренная Женевская шкала (ТЭЛА), ШОКС при ХСН. |
| **Педиатрия** | Нормы по возрасту (масса, рост, ЧДД, ЧСС, АД, порог гипотензии), шкала Апгар с секундомером от рождения. |
| **Справочники** | МКБ-10 (11 841 запись, поиск по коду и названию), группа крови по таблице цоликлонов, срок беременности и дата родов. |

Ещё в приложении:

- **Работает без сети.** Препараты, нормы и МКБ-10 хранятся внутри приложения.
- **Светлая и тёмная тема.** Значок луны или солнца в правом верхнем углу; долгое нажатие
  возвращает тему телефона.
- **Доступность.** Подписи для TalkBack и VoiceOver на русском, результат озвучивается,
  крупный системный шрифт до 150 %.
- **Без учётных записей.** Данные пациента хранятся только в памяти и стираются при закрытии;
  истории расчётов и передачи данных нет.

Подробная инструкция по каждому экрану и полный список препаратов — в
[USER_GUIDE.md](USER_GUIDE.md).

## Откуда берутся цифры

Приоритет источников:

1. Действующие клинические рекомендации МЗ РФ, приказы МЗ РФ.
2. Инструкции к препаратам, зарегистрированным в РФ (ГРЛС).
3. Если российского источника нет — ERC, AHA/PALS, BNF for Children, оригинальные публикации шкал,
   документация производителей трубок, аппаратов ИВЛ и дефибрилляторов.

Если источники расходятся, берётся российский вариант, а без него — самый осторожный. У каждой
дозы, предела и порога в коде есть комментарий с документом, годом и разделом.

**Проверка.** В октябре 2026 года все расчёты прошли аудит: 428 позиций сверены с источниками
и проверены запуском кода. Найденные расхождения исправлены, а то, что оставлено сознательно,
объяснено в коде. Расчёты покрыты автотестами (Jest), CI проверяет каждый
pull request. Клиническую валидацию расчёты не проходили: перед выпуском дозы, пороги и тексты
должен подтвердить врач.

## Запуск

Нужны **Node.js 22** (версия в `.nvmrc`) и npm. Для нативной сборки — Android Studio или Xcode
(только macOS).

```bash
git clone https://github.com/Tishe698/DocHub.git
cd DocHub
nvm use        # Node из .nvmrc
npm ci         # зависимости строго по package-lock.json

npm start      # Metro и QR-код для Expo Go
npm run android
npm run ios
npm run web    # веб-версия в браузере
```

В Expo Go видео на экране «Срок беременности» может не воспроизводиться, в собранном приложении
оно работает.

### Сборка

```bash
npx eas build --platform android --profile preview      # APK для установки
npx eas build --platform android --profile production   # сейчас тоже APK (см. eas.json)
npx eas build --platform ios --profile production
```

Для Google Play нужен AAB: в профиле `production` файла `eas.json` замените
`"buildType": "apk"` на `"buildType": "app-bundle"`.

## Разработка

| Команда | Что делает |
|---|---|
| `npm test` | Jest (`jest-expo`); тесты лежат рядом с кодом в папках `__tests__/` |
| `npx jest <путь>` | тесты одного модуля, например `npx jest defibrillation` |
| `npm run lint` | ESLint 9 с правилами хуков React |
| `npm run format` / `npm run format:check` | Prettier 3: исправить или только проверить |

**CI** ([`.github/workflows/ci.yml`](.github/workflows/ci.yml)) запускается на каждый pull request
и push в `main`: `npm ci` → линтер → форматирование → тесты → пробная сборка Android-бандла.

<details>
<summary><b>Правила для изменений</b></summary>

1. Логика расчёта — в чистом модуле рядом с экраном (без React), тест — в `__tests__/` рядом.
2. Новый экран: папка модуля → маршрут в `ROUTES` в `App.js` → карточка в
   `main_screen/menuConfig.js`. Тест `menuConfig.test.js` упадёт, если у маршрута нет карточки.
3. Экран собирается из `components/Screen` и `components/ui`, цвета — только из
   `useTheme().colors`, данные пациента — из `patient/PatientContext`.
4. Новый препарат — запись в нужном файле `js_button_preparation/formula_groups/`. Путь введения —
   `routeInput([...], 'iv')`, показание — `choiceInput(...)` из `js_button_preparation/routes.js`.
5. У каждого клинического значения (доза, максимум, порог, строка таблицы) — комментарий
   с источником: документ, год, раздел.
6. Перед pull request: `npm run lint`, `npm test`, `npm run format:check`; обновите документацию.

Подробнее — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md): тема, компоненты, доступность, общий
пациент, пути введения, тесты.

</details>
